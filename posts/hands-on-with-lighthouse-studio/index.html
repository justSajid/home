A Place for my Research, Activities and Thoughts

Hands-on with Lighthouse Studio (1/2)

Published September 11, 2020 in Analytics by justSajid 5 min read
Table of Contents

Overview

Lighthouse Studio is a platform for creating questionnaires and applying specialized research techniques such as Maximum Difference Scaling (MaxDiff) and conjoint (trade-off) analysis.

Hands-On (Creating Questioner)

Once the lighthouse studio is installed on the windows machine, simply start it.

We'll have the home screen at the front of us;

Now to create a new study, simply click on the New button to create the New Button;

And give the study required name in an appropriate location and click OK;

We will have the write questionnaire dialog at the front of us, (Also we can do that by clicking compose >> Write Questionnaire from the top menu bar or by clicking Write icon in the toolbar);

Here, we can see all the questions that are currently in our survey. The "Start" question automatically add to the first page of our survey. (Later on, when we provide a survey link to launch the questionnaire, this Start "question" is actually not seen by the respondent and is used instead for specifying passwords and other related settings).

Now to modify this Start question, we can simply click 'Edit' button by highlighting this Start question.

Now we can see the 'Questionnaire Access and Password' dialog;

Here, we can customize what the respondents will see on the first page of the survey. Like here, we can also specify the respondent password if we want to make our survey password protected.

As we can see here, each question has different text areas. Will show on screen accordingly as 'Header 1', 'Header 2' and 'Footer'. So we can visualise our text appropriately.

E.g. In 'Header 1' we can write the details about the question. Like "Welcome to our survey! Today we are interested in AI use during the pandemic times. Please type your user name and password and then click the “Next” button to continue…"

We can simply write that as it is, and also use the 'Pencil ✏️ ' button on the right side of the text bar to further customize the text. This gives us more freedom to customize the text as per our need by using the simple HTML tags;

Make the survey password protected;

Well, as its an optional for us to make our survey password protected. Perhaps to do that, we can easily do the following steps;

i) While editing the Start question, simple click upon the 'Password Fields';

ii) We can add a number of password fields here, perhaps normally it is typical to include just one or two password fields. In our survey, we'll be using a username and a password. We'll name the variables (fields) myusername and mypassword. (The datatype for username can be 'Text' To mask the user password we can simply click the 'Masked' option, perhaps we can also use case sensitive option if we want).

Now if we click upon the preview, we can see the Preview of how this will look like;

* A common approach is to provide respondents a "one-click link" which already includes the respondent's password in the link (the URL), so that respondents just click the link and immediately bypass the Start question and begin the survey at the question directly following the Start question. But, for this quick-start understanding, we can assume that we will send a generic link to the Start page for each respondent.

iii) Now, to provide the exact username, password, simply click upon Password Data button;

This will popup the message that, changes to password and merged fields must be saved. And on continue to Password Data, 'Cancel' will no longer be available.

iv) Now, here we can simply provide the UserName and Password that the respondent will have to enter before entering our survey;

* (1000 max respondents mean, the username and password can be used by a maximum of 1000 users).

We can also do the auto-generated password, as well as we can Import the passwords.

In most studies, each respondent receives a unique password combination. I.e. Each respondent receives a unique password combination (Max Respondents = 1). With unique passwords for each respondent, respondents that terminate early can return and restart the survey where they left off.

v) Once, Password Data is set, simply click Close button. And thats it.

Adding Questions;

Whenever we add a question to the List of Questions, the new question is placed directly below whatever question (or page break) is highlighted. If no question is highlighted, then the new question is placed at the bottom of the list. If you want to rearrange the questions within the list, you can highlight them and use the "Up" and "Down" arrows next to the list. Or, you can cut, copy, and paste questions by using the cut, copy, and paste icons.

i) To add new question, simply click the Add button.

ii) The 'Add to Questionnaire' dialog is shown. Here we can simply select the question type, simply select the question type and click OK;

iii) Now, it will ask for the question name, simply give it an appropriate name and press OK;

iv) Now similarly add the question content here. E.g. In Header 1, write the question statement;

v) Now as this question requires just a single response (a radio button), so we should click the Settings tab and select the Radio button (single response) in the upper-left-hand corner of this dialog (it is already selected by default).

vi) Now, to add options, simply click on the 'Response Options' tab;

vii) Now, simply keep adding option by clicking on the Add button. To add more options simply do enter twice and give the another option;

* It is a good practice to already have the questionnaire dataset ready either in word or excel, hence it will be a simple copy pasting activity here.

viii) To review how our question look like, simply click Preview, we will have the question demonstration at the front of us;

Similarly, we can keep adding the questions...

ix) When our questionnaire is complete, we can simply conclude our survey. For that we simply select the question category as terminate;

x) Now, simply add conclusion remarks as, "Thank you very much. That's all we need to know today";

x) For better visualization, we can 'Add Page Breaks', by clicking upon the question and click Add Page Break;

Now to test the whole survey, go to 'Test' from top menu bar and select Test Servey, this will take us to browser where we can test all the whole questionnaire;
